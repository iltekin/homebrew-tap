# iltekin/homebrew-tap

Homebrew casks for apps by [Sezer Iltekin](https://github.com/iltekin).

```bash
brew install --cask iltekin/tap/unplug
```

| Cask | Description |
|---|---|
| [unplug](https://github.com/iltekin/unplug) | Menu bar app to turn external displays off and on |

## Updating a cask

Casks here are generated by each app's release script. For Unplug, follow [RELEASING.md](https://github.com/iltekin/unplug/blob/main/RELEASING.md) in the app repository: publish the GitHub release first, then copy the generated `packaging/unplug.rb` to `Casks/unplug.rb`, commit and push.
